# Hotel & Restaurant Website

A responsive Hotel and Restaurant website built using HTML, CSS, and JavaScript.

## Features

- 🏨 Hotel information and room details
- 🍽️ Restaurant and menu section
- 📱 Responsive design for mobile, tablet, and desktop
- 🖼️ Attractive image gallery
- 📞 Contact section
- 🧭 Easy navigation
- ✨ Interactive elements using JavaScript

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Purpose

This project was created to practice front-end web development and build a user-friendly, responsive website for a hotel and restaurant.
